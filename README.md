# 달빛 저수지

밤 저수지에서 물고기를 낚아 수조에서 키우고, 번식시켜 우주 등급까지 진화시키는 브라우저 게임이에요.

**플레이:** https://leenamgyeol-spec.github.io/moonlake/

## 이렇게 놀아요

- **낚시**: 찌를 던지고, 찌가 들어가면 챔질해요. 누르고 있으면 감기, 떼면 풀기예요.
- **희귀도**: 일반, 고급, 희귀, 영웅, 전설, 신화, 우주 일곱 등급에 31종이 있어요. 알비노와 무지개 변종도 있어요.
- **번식**: 새끼는 얼굴, 몸통, 꼬리, 지느러미, 무늬, 색을 부위마다 부모 한쪽에게서 그대로 물려받아요. 성어가 되는 데 30초 걸려요.
- **자동 낚시**: 성공률 100%. 처음 켤 때 뜨는 결제 화면은 흉내만 낸 거라 실제로 돈이 나가지 않아요.
- **저장**: 자동 저장, 그리고 다른 기기로 옮기는 저장 코드.
- **랭킹**: 순자산 순위표 (`worker/`의 Cloudflare Worker).
