# 달빛 저수지

밤 저수지에서 물고기를 낚아 수조에서 키우고, 번식시켜 전설 등급까지 진화시키는 브라우저 게임이에요.

**플레이:** https://leenamgyeol-spec.github.io/moonlake/

## 이렇게 놀아요

- **낚시**: 찌를 던지고, 찌가 들어가면 챔질해요. 누르고 있으면 감기, 떼면 풀기예요. 물고기가 날뛸 땐 손을 떼야 줄이 안 끊겨요.
- **희귀도**: 일반, 고급, 희귀, 영웅, 전설 다섯 등급에 16종이 있어요. 알비노와 무지개 변종도 있어요.
- **번식**: 다 자란 두 마리를 붙이면 치어가 태어나요. 다른 종끼리, 변종끼리 섞으면 윗등급으로 진화할 확률이 올라가요. 변종은 한쪽 부모면 60%, 양쪽 부모면 90% 확률로 유전돼요.
- **자동 낚시**: 스위치로 켜고 꺼요. 처음 켤 때 뜨는 결제 화면은 흉내만 낸 거라 실제로 돈이 나가지 않아요.
- 진행 상황은 브라우저에 자동 저장돼요.

파일 하나(`index.html`)로 돌아가고, 빌드는 필요 없어요.
